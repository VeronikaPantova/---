# DIO — Bulgarian Crosswords & Puzzles Website

Short description
- DIO is the official website for DIO, a Bulgarian brand specializing in crosswords and word puzzles.

Main purpose
- Provide a simple, accessible web presence for DIO to showcase puzzles, publish new crosswords, share answers and news, and let visitors try puzzles online.

Technologies used
- HTML
- CSS
- JavaScript

Main website sections
- Home: Brand overview and featured puzzles.
- Puzzles: List of current crosswords and puzzles (playable or downloadable).
- Answers: Solutions and answer archives for past puzzles.
- News / Blog: Announcements, puzzle highlights, and editorial content.
- Contact: Contact information and submissions for puzzle ideas.

How to run locally
1. Clone or copy the project files to your machine.
2. Open the project folder and launch a local file server or open `index.html` directly in your browser.

Simple local server examples:

- Using Python 3 (recommended):

```bash
# From the project root directory
python -m http.server 8000
# Then open http://localhost:8000 in your browser
```

- Using VS Code Live Server extension: open the project and click "Go Live".
